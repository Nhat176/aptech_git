Trong bài thực hành này, tôi đã làm quen với các lệnh cơ bản của Git và GitHub. Đầu tiên, tôi kiểm tra phiên bản Git bằng lệnh git --version. Tiếp theo, tôi tạo một local repository bằng lệnh git init. Tôi sử dụng git status để kiểm tra trạng thái của repository. Sau đó, tôi lần lượt thêm từng file bằng git add và tạo các commit riêng biệt bằng git commit. Tôi tạo file .gitignore để bỏ qua thư mục __pycache__/ và file .env, sau đó commit các thay đổi. Tiếp theo, tôi sử dụng git log --oneline và git log --stat để xem lịch sử commit và các thay đổi của từng commit. Sau đó, tôi tạo một repository trống trên GitHub, kết nối repository cục bộ bằng lệnh git remote add origin, kiểm tra kết nối bằng git remote -v, đổi tên nhánh sang main bằng git branch -M main và đưa dự án lên GitHub bằng git push -u origin main. Cuối cùng, tôi thêm hai file README.md và LICENSE, commit các thay đổi và sử dụng git push để cập nhật repository trên GitHub. Qua bài thực hành này, tôi hiểu được quy trình làm việc cơ bản với Git và GitHub.
